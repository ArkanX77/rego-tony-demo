# Maquette — Entreprise REGO Tony Père & Fils

Site vitrine statique en HTML, CSS et JavaScript, prévu pour GitHub Pages.

## Mise en ligne / remplacement des fichiers
1. Ouvrir le dépôt GitHub `ArkanX77/rego-tony-demo`.
2. Remplacer `index.html`, `style.css`, `script.js` et `README.md` par ceux de cette archive.
3. Valider les changements (Commit changes). GitHub Pages publiera la nouvelle version automatiquement.

## À valider avant publication définitive
- Les visuels de la galerie et de la page d'accueil sont des images d'illustration distantes. Remplacer par des photos de chantiers appartenant à l'entreprise ou utilisées avec autorisation.
- Confirmer l'adresse, les prestations détaillées et la mention « 35 ans d'expérience ».
- Le formulaire prépare un courriel dans la messagerie du visiteur ; il n'envoie pas les demandes sur un serveur.
- Les polices Google Fonts et les photos distantes nécessitent une connexion internet.

## Fichiers
- `index.html` : contenu et structure
- `style.css` : mise en page responsive
- `script.js` : menu mobile, année automatique et préparation du courriel
